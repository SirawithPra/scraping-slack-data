## สองเรื่องที่ทำให้ไม่ต้องกังวลเรื่องเลือกรูป

**รูปคนละตัว คนละแสง คนละกล้อง จะออกมาดูเป็นชุดเดียวกัน** เพราะทุกรูปถูกดันผ่าน
duotone เดียวกัน — ทำเป็นขาวดำก่อน แล้วทับด้วยสี accent ของโปรเจกต์ในโหมด `color`
เลือกรูปที่ชอบได้เลย ไม่ต้องหาโทนให้เข้ากันเอง

**ยังไม่ใส่ก็เปิดได้** ช่องที่ไม่มีไฟล์จะถอด `<img>` ตัวเองออก (`onerror`) แล้วโชว์กรอบ
ที่มีลายอุ้งเท้าแทน — ไม่มีไอคอนรูปแตกโผล่กลางห้องประชุม

## ข้อควรรู้

- **jpg เท่านั้น** ตามชื่อไฟล์ในเด็ค ถ้าจะใช้ png/webp ต้องแก้ `src` ใน `deck.html`
- ตัดรูปให้แมวอยู่ตรงกลาง เพราะกรอบใช้ `object-fit: cover` — ขอบจะถูกตัดตามสัดส่วน
- ไฟล์ใหญ่เกินไม่ต้องกลัว แต่ถ้าเด็คหนักเกิน 10 MB จะเปิดช้าตอนพรีเซนต์
- **รูปพวกนี้ไม่ได้ commit ขึ้น git** (ดู `.gitignore` ในโฟลเดอร์นี้) เพราะรูปส่วนตัว
  ไม่ควรอยู่บนรีโป public — เก็บไว้เครื่องตัวเองพอ
